# Fighter Khey

Le jeu de baston entre potes. Fichier unique `index.html`, jouable sur téléphone (plein écran, installable sur l'écran d'accueil, fonctionne hors ligne).

Polices intégrées : Anton, Bangers, Barlow Condensed (SIL Open Font License).

Voix de l'annonceur : « Voiceover Pack: Fighter » de Kenney (www.kenney.nl), licence CC0, retravaillée pour le jeu.
Noms des combattants : voix de synthèse Kokoro (Apache 2.0) convertie vers le timbre de l'annonceur avec kNN-VC (MIT).
